# HabitatGuard
An ESP32-based sensor-driven intake screening and survival forecasting for off-Earth habitats.

# Team
Cohen Cunningham, William Dang,  Mai Tran, Phuong Tran, and Muntrail

# About
Everything entering the habitat
must be checked first. Anything a robot brings to it must be inspected for any toxic or spoiled material present. Currently, crew members must inspect items by hand, wasting valuable time that can be spent analyzing extraterrestrial data.
